## 2026-11-04 - Accessible labels for paired number and range slider inputs
**Learning:** In interactive simulation dashboards where numeric inputs are paired side-by-side with range sliders for the same parameter, providing the identical label (or omitting the label on the range slider) causes screen reader announcements to either collide or become ambiguous ("Masa, edit text" followed by "unlabeled slider" or redundant "Masa, slider"). Specifying explicit, descriptive `aria-label`s differentiating the slider control (e.g., `Masa (deslizador)`) clarifies the input modality for assistive tech users.
**Action:** When designing or refactoring paired numeric and slider parameter controls, ensure each interactive control has a distinct accessible name indicating its specific control type or purpose.
