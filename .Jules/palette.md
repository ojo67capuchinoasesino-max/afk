## 2026-09-12 - Interactive Slider and Icon Button Accessibility in Single-File Static App
**Learning:** In dual-control input groups (paired number input and range slider), omitting `aria-label` from range sliders leaves screen reader and assistive technology users unable to identify what the slider modifies, even if the neighboring number input is labeled. Similarly, icon-only buttons with only `title` attributes lack standardized `aria-label` accessible names across various screen readers.
**Action:** When designing or maintaining paired input widgets and icon controls, ensure both the slider (`<input type="range">`) and the number input (`<input type="number">`) share descriptive accessible names via `aria-label`, and provide explicit `aria-label` attributes on icon-only trigger buttons.
