## 2025-05-10 - Accessibility for Dual Controls and Tab Navigation in Static HTML Applications
**Learning:** In static single-file web applications with interactive physics controls, slider `<input type="range">` elements paired visually with `<input type="number">` controls require explicit `aria-label`s on both inputs. Additionally, icon-only action buttons (such as simulation controls) and sub-navigation tab bars need explicit `aria-label`, `role="tablist"`, `role="tab"`, and `aria-selected` attributes to ensure screen reader users can understand and navigate workspace modules.
**Action:** When working on pre-rendered or single-file static HTML interfaces, audit paired range/number controls and icon-only action buttons to guarantee complete ARIA labelling and tablist roles.
